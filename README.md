# 🍲📖🥣 Famous Recipe App🍲📖🥣
A beautifully designed mobile application for exploring recipes, fetching real-time data from a public Recipe API, and displaying it in a smooth, user-friendly interface.

## 🔧 Tech Stack

    🔹 Framework: Flutter
    🔹 Language: Dart
    🔹 State Management: Set State
    🔹 API Handling: REST API + JSON
    🔹 IDE: VS Code\

## ✨ Features
    
    🔹 Fetch recipes with ingredients & steps via API
    🔹 Recipe detail screen with cooking instructions and ingredients
    🔹 Responsive design for both Android and iOS
